## 二、关键根因记录（下次别再踩）

1. **`Path.as_uri()` 不接受相对路径** → 抛 ValueError 被 `try/except: continue` 吞掉 → 表现为「行情面板为空」假成功。**一律走 `data/cache.py` 的 `db_uri(p)`**。
2. **`ranking_v2.py` 曾硬编码 `D:/劳威派量化数据/` 旧机器路径** + 裸 `f"file:{path}?mode=ro"` 拼法（中文路径非法）→ 三层池静默失败。已改为 `CACHE_DIR` + `db_uri()`。
3. **`data/logs_archive.py` 的 `TRASH = Path("<home>/Desktop/垃圾桶")` 是占位符残留**（发行包脱敏未替换），归档步骤实际 failed。**待修复**：改成真实归档目录（低优先，不影响主流程）。
4. **pyarrow / py7zr 装在系统 Python311**（`C:\Users\34111\AppData\Local\Programs\Python\Python311\python.exe`），**不是** workbuddy venv。跑 DSHQuant 一律用 Python311。
5. **装新包后必须重启 deck 服务**（pandas/pyarrow 扩展注册冲突 "pandas.period already defined"）。

#### 真实持仓文件格式（二选一，注意两条路径）
```json
// logs/portfolio.json  ← sim_tracks.py --live 用（固定名）
// logs/portfolio_YYYYMMDD_HHMMSS.json  ← take_profit_check.py 用（时间戳，glob 取最新）
{
  "version": 1,
  "updated_at": "2026-10-15 15:00:00",
  "max_positions": 5,
  "positions": [
    {"code": "001256.SZ", "name": "炜冈科技", "entry_date": "2026-10-15",
     "entry_price": 22.5, "target": 28.0, "stop": 20.0,
     "otype": "quality_gap", "risk_level": "low", "status": "holding"}
  ],
  "history": []
}
```
要点：`status` 必须是 `"holding"`（或 `"over_limit"`）止盈引擎才会纳入；`take_profit_check` 与 `sim_tracks --live` 读的是**不同文件**，若想两处一致，可写一份固定名 `portfolio.json` 后另存一份带时间戳的副本。

## 四、数据流（一句话）

```
7z分钟数据 → parquet ─┐
Tushare/baostock日线 → bars.db ─┼→ 扫描(scan) → 机会池 → Pitch → 三层池 → 择时 → 今日信号 → 止损/风控 → 远期池 → 归档
                       └→ 因子池/财报/质量库 → 风控(Beneish)/估值
```
所有读取只经 `data/cache.py`（SQLite 唯一读取接口），断网不影响已缓存数据。
