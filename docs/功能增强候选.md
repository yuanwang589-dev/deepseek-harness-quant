## 二、候选项目与可加装功能（按推荐度排序）

### 1. microsoft/qlib（44.6k★，MIT）—— 因子工程 + ML 训练 + 回测一体化
- **现状差距**：DSHQuant 的选股信号以规则/评分法为主，无标准化因子库、无 ML 模型层、无系统回测报告。
- **可借鉴/加装**：
  - Alpha158/Alpha360 因子集（K线形态/动量/波动/量价相关等 158 个表达式）→ 作为 `factors/` 新因子族的参考实现，与现有 otype 体系对照；
  - DataHandler→Model→Strategy→Backtest→Recorder 流水线抽象 → 回测报告（IC/年化/最大回撤/信息比率）目前 DSHQuant 缺失；
  - **防未来函数**设计（label 用 `Ref($close,-2)/Ref($close,-1)-1`，T 日盘后决策 T+1 成交）→ 正是我们 T+1 纪律的形式化，可用来审计现有信号。
- **接入方式**：`pip install pyqlib`（Python 3.8–3.11；本 venv 是 3.11 ✓）。不必全量接，先取 Alpha158 表达式做因子对照实验。
- **风险**：框架重、学习曲线陡；仅借鉴表达式与评估指标，勿整体引入。

### 2. microsoft/RD-Agent（14.3k★，MIT）—— LLM 自动挖因子
- **现状差距**：因子/信号迭代全靠人工。
- **可加装**：与已接入的 DeepSeek HARNESS 结合，做"LLM 提出因子假设 → 实现 → 回测 → 迭代"的夜间自动研究循环（对标其 factor-mining demo）。
- **风险**：LLM 生成代码需沙箱隔离执行；产出必须过人工评审（不替代人的判断）。

### 3. vnpy / VeighNa（27.8k★，MIT）—— 实盘风控与交易执行
- **现状差距**：DSHQuant 风控是"信号级"（止损/止盈/回撤），缺"订单流/账户级"风控（单笔限额、当日累计亏损熔断、活跃订单清理）。
- **可借鉴/加装**：
  - `RiskManager` 设计（订单流控 + 数量限额 + 登录即清理活跃单）→ 补到 `risk/`，作为未来接真实账户的前置；
  - CTA 模板的 ATR 跟踪止损实现 → `stop_matrix_v2` 已有 `atr_stop_mult` 字段但无实际计算，可补齐。
- **风险**：vnpy 体积大；只移植 RiskManager 思路与 ATR 算法，不引框架。

### 4. aifa-quant（MIT，个人项目，活跃）—— 本地优先研究闭环 + 多层风控
- **现状差距**：组合层缺"仓位管理"维度（DSHQuant 按等权整手）；缺市场体制过滤。
- **可加装**（与本系统契合度最高）：
  - **市场体制过滤**（熊市自动暂停建仓）→ 与现有 `timing_system`/择时趋势卡合并；
  - **行业集中度上限** → `portfolio_pnl` 已有 industry_exposure 统计，加一条上限规则即可；
  - **波动率目标仓位 sizing**（替代等权）→ 改 `sim_live_1w` 的分配逻辑；
  - 5 种投资者画像（factor_weights 分化）→ 门户可按画像重排候选。
- **风险**：个人项目，代码质量需评审后取用。

### 5. qf-lib（quarkfin，852★，MIT）—— 事件驱动回测 + 防未来函数 + PDF 报告
- **可加装**：事件驱动回测骨架（回测逻辑=实盘逻辑，杜绝"回测很美实盘翻车"）；跑完生成 PDF 报告。
- **注意**：依赖 WeasyPrint（Windows 需 GTK3 运行时），仅在有 PDF 报告需求时引入。

### 6. PandOvo/quant-backtest-portfolio_akshare（轻量 A 股回测模板）
- **可加装**：YAML 配置 + 参数扫描 + 多策略横向对比 + 月度收益热力图；风控版双均线（止损/移动止损/趋势过滤/波动率目标仓位）可作为"增强双均线"对照基线。
- **定位**：教学/对照模板，适合新人带练（符合团队"评审带练"用法）。

### 7. QUANTAXIS（25k★）—— 全市场数据架构参考
- **可加装**：其多数据源适配层（QA  fetcher 体系）可对照优化 `data/fetcher_*.py` 的失败重试与降级；分钟/Tick 存储方案可参考（我们分钟数据是付费边界，先不动）。
