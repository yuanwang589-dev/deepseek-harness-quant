## 1. 服务与端口

| 服务 | 端口 | 启动方式 | 守护 |
|---|---|---|---|
| 量化决策台 deck | 8787 | `./run_dshq.sh launcher.py` | `com.dshq.deck`（launchd KeepAlive） |
| AI 控制台 HARNESS | 3080 | `./run_harness.sh` | `com.dshq.harness`（launchd KeepAlive） |
| 盘后全域更新 | — | `scripts/after_close_update.py` | `com.dshq.afterclose`（周一~周五 15:20） |

三个 launchd 任务都在 `~/Library/LaunchAgents/`：

```bash
launchctl list | grep dshq                       # 看三个任务状态（PID / 退出码 / label）
launchctl print gui/$(id -u)/com.dshq.deck       # 看 deck 守护详情
launchctl kickstart -k gui/$(id -u)/com.dshq.afterclose   # 立刻跑一次盘后更新（等同 15:20）
launchctl bootout gui/$(id -u)/com.dshq.deck     # 暂停 deck 守护（调试用）
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dshq.deck.plist  # 恢复
```

手动启停（不经 launchd，会与 KeepAlive 抢端口，调试时先 bootout）：

```bash
bash start_all.sh                  # 一键起 deck + HARNESS
lsof -i :8787 -i :3080 -P          # 查占用
```

日志：`logs/deck.log`、`logs/harness.log`、`logs/deck_launchd.log`、`logs/harness_launchd.log`、`logs/scheduled_update.log`。

## 2. 每日闭环（15:20 自动）

```

  └─ scripts/after_close_update.py

data/manual_update_worker.py 共 23 步：
  ① 分钟 7z 增量 → parquet（本机无分钟源，空跑 0s）
  ② 日线增量：Tushare 失败 → akshare 现货兜底（写当日缺口 + 修 is_st）

  ④ 竞价强度（原版，需 1 分钟数据）
  ⑤ 行业归属（申万一级，7 天新鲜度）
  ⑥ 竞价强度代理（5 分钟 bar，池内 ~127 只）
  ⑦ 估值快照（akshare 现货）
  ⑧ 机会扫描 --pitch
  ⑨ Pitch v2 Deck
  ⑩ 远期池入池（Pitch → track，T+1/5/20/60 追踪的起点）
  ⑪ 三层池（观察/候选/决策）
  ⑫ HARNESS 状态快照
  ⑬ 今日信号（今日信号 + 数据审计 + 日报，重建版）
  ⑭ 新择时系统
  ⑮ 沪深300 指数日线
  ⑯ Regime 仓位档（MA6/12 红绿灯）
  ⑰ 三层池复算（用最新 Regime）
  ⑱ 今日信号复算
  ⑲ 因子池产物（重建版：daily_scores/manifest/snapshot/risk_multiplier）
  ⑳ 因子健康度（月度 IC 重建）
  ㉑ 科技突破池（tech_pitch_v3）
  ㉒ 远期收益更新 + 止损监测
  ㉓ 全站健康扫描 + 时间戳归档
```

一次全跑约 **9–12 分钟**（大头是估值 60s、竞价代理 5–6 分钟、科技池 45s）。

## 3. 数据源与刷新方式

| 数据 | 脚本 | 频率/耗时 | 守卫 |
|---|---|---|---|
| 日线（当日缺口） | `data/incremental_daily_spot.py` | 每日，~70s | **盘中 09:15–15:10 拒写**；交易日历校验；只 `INSERT OR IGNORE` |

## 4. 排障手册

| 症状 | 先查 | 处置 |
|---|---|---|
| 页面打不开 / 全站 404 | `launchctl list \| grep dshq`；`lsof -i :8787` | `launchctl kickstart -k gui/$(id -u)/com.dshq.deck` |
| 数据停在昨天 | `curl -s localhost:8787/api/update_status` | 报「busy」就等；报完成但日期旧 → 看 `logs/manual_update_*.log` 的日线步骤 |
| 机会池/扫描为空 | 扫描输出是否「行情面板为空」 | 检查 `LWQUANT_CACHE_DIR` 指向 `data/cache`、`bars.db` 是否存在 |
| 竞价页空 | `ls logs/auction_signal_proxy_*.json` | `python data/fetch_auction_proxy.py --days 10` |
| 远期池空 | `ls logs/pitch_track_pool_*.json` | 从未入池：`pitch_track.py --append logs/pitch_v2_*.json`（管道已自动做） |
| 因子页空 | `ls data/factorpool/output/daily_scores/` | `python data/build_factorpool.py` + `build_factor_health.py` |
| 健康扫描红 | `python -m json.tool report/health_scan_latest.json` 看 `bad` | 按缺失项补；「样本未积累」类已白名单 |
| 日线没写今天 | 是否在 09:15–15:10 或节假日 | 守卫正常行为；收盘后手动 `incremental_daily_spot.py` |
| launchd 没触发 | `launchctl print gui/$(id -u)/com.dshq.afterclose` | 检查 Mac 是否睡眠（唤醒后补跑一次）；确认 plist 在 `LaunchAgents` 且已 bootstrap |
| 采样数据口径不对 | `turn`/`pct_chg` 是 0.02 还是 2.0 | bars.db 统一为小数；现货写入已 ÷100 归一 |

## 5. 已知缺口（诚实清单）

| 缺口 | 影响的功能 | 现状 / 补法 |
|---|---|---|
| 原厂 `report/` 包未随仓库分发 | 今日信号 / 日报 / 审计的原始实现 | 已用 `report/daily_signal.py` 重建（产物标 provenance，只聚合不另造结论） |
| 原厂 123 因子池（`data/factorpool` 产物） | 因子档案 / 因子表现 / 强因子直通 | 仅有重建版 40 因子面板 + 21 因子月度 IC；因子档案页仍空 |
| 分钟数据（1 分钟 7z） | 原版竞价因子、分钟因子、7z 增量步骤 | 竞价用 5 分钟代理（127 只）；其余空跑 |
| Tushare token 未配置 | 官方盘后日线增量、tushare 财务源 | akshare 现货兜底；填 `config/params.yaml` 后自动接管 |
| Pitch 审批未开始 | 决策记录 / 审批复盘 / 数据导出 | 需人工在 `/pitch` 点 buy/drop |
| 远期池刚建 | T+1/5/20/60 收益 | 9 只已入池（entry 2026-11-11），按交易日后填 |
| 行业为申万一级 | 行业上限较粗（31 类） | 需要更细可切 `fetch_industry.py --level em`（东财细分，多级混用需自行归一） |

## 6. 本机修改记录（2026-11-11）

**移植类（若不修，整条链在这台机器上是空跑）**
1. 35 个文件 50 处 Windows 路径 `data\cache\...` → `data/cache/...`
2. 9 处 `Path.as_uri()` 对相对路径抛异常 → 加 `.resolve()`
3. `strategy/ranking_v2.py` 开发者绝对路径 `D:/劳威派量化数据/...` → `CACHE_DIR`
4. `config/params.yaml` 的 `cache_dir: "<your-config>"` → `data/cache`
5. `backtest/bt_runner.py` 三处硬编码 2020 年门槛 → 按 bars 实际起点动态计算
6. `live_api.py` / `batch_minute_7z.py` / `_diag_path.py` 残留反斜杠路径

**数据类**
7. `factors/opportunities/scan.py`：`load_quality` 空库降级、`load_fundamentals` 补 `gross_margin` 占位、`load_st_codes` 名称兜底、`load_valuation` 本地快照兜底
8. `factors/opportunities/backtest_winrate.py`：PIT 面板补 `non_lowprice`（原缺列 → 回测/模拟盘 KeyError）
9. 现货写入的 `turn`/`pct_chg` 百分数 → 小数（360 行回填）；`build_hist_mv` 口径自适应

**新增**
10. `data/fetch_valuation.py`、`incremental_daily_spot.py`、`fetch_industry.py`、`build_factorpool.py`、`build_factor_health.py`、`fetch_auction_proxy.py`、`harness_state.py`
11. `report/daily_signal.py`、`scripts/after_close_update.py`
12. launchd 三个任务（deck/harness 常驻 + 15:20 盘后）

## 7. 迁移到新机器的步骤

```bash
# 1) 代码（含 harness/node_modules 的完整包）
#    注意：Release 页下载 DSHQuant-*.zip；Source code.zip 不含 harness 运行时

# 2) Python 环境
python3 -m venv dshq-venv && dshq-venv/bin/pip install -r requirements.txt pyarrow

# 3) 数据（仓库不分发行情，需自行获取）
#    data/cache/bars.db + finance.db + stock_basic.db 至少三项；
#    或用演示数据：python data/demo/build_demo_db.py && LWQUANT_CACHE_DIR=data/demo
python data/fetch_stock_basic.py
python data/incremental_daily_spot.py        # 当日行情（收盘后）

# 4) 配置
cp config/params.yaml.example config/params.yaml     # 填 tushare_token（可留空，走现货兜底）
cp harness/home/.credentials.yaml.example harness/home/.credentials.yaml  # 填 DeepSeek Key

# 5) 起服务 + 装守护（按本机路径改 plist 里的 BASE）
bash start_all.sh
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dshq.deck.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dshq.harness.plist
launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/com.dshq.afterclose.plist

# 6) 验收
curl -s localhost:8787/api/update_status
curl -s -X POST localhost:8787/api/manual_update
python data/health_scan.py
```
