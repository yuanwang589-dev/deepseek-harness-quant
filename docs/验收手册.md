for p in sorted(pathlib.Path("data/cache").glob("*.db")):

    r = c.execute("PRAGMA integrity_check").fetchone()[0]

## 5. WAL 与只读连接（约 5 秒）

```bash
..\.venv\Scripts\python.exe - << 'EOF'
import sqlite3, pathlib
from data.cache import db_uri
for p in sorted(pathlib.Path("data/cache").glob("*.db")):
    c = sqlite3.connect(str(p)); m = c.execute("PRAGMA journal_mode").fetchone()[0]; c.close()
    uri = db_uri(p)
    print(f"{p.name:28s} journal={m:6s} immutable={'immutable=1' in uri}")
EOF
```

**判定**：`journal=wal`；最近 5 分钟被写过的库 `immutable=False`，静止库 `True`。

**并发验证**（写 2 万行同时读 50 次，应 0 错误）：

```bash
..\.venv\Scripts\python.exe - << 'EOF'
import sqlite3, tempfile, threading, time
from pathlib import Path
from data.cache import db_uri
d = Path(tempfile.mkdtemp()); db = d/"t.db"
c = sqlite3.connect(db); c.execute("PRAGMA journal_mode=WAL")
c.execute("CREATE TABLE t(x)"); c.commit(); c.close()
err = []
def w():
    x = sqlite3.connect(db, timeout=15)
    for b in range(20):
        x.executemany("INSERT INTO t VALUES (?)", [(i,) for i in range(1000)]); x.commit()
    x.close()
def r():
    for _ in range(50):
        try:
            q = sqlite3.connect(db_uri(db), uri=True, timeout=5)
            q.execute("SELECT COUNT(*) FROM t").fetchone(); q.close()
        except Exception as e: err.append(e)
        time.sleep(0.002)
a, b = threading.Thread(target=w), threading.Thread(target=r)
a.start(); b.start(); a.join(); b.join()
print("errors:", len(err))
EOF
```

**判定**：非空 ≥ 250,000；`600519` 的 `2026-03-31` 期披露日为 2026-04-25 左右（真实公告日）。

## 8. 失败怎么办

| 现象 | 先查 |
|---|---|
| `database is locked` | 是否还有旧进程持有 DELETE 日志模式的连接；跑一次 `data/enable_wal.py` |
| `disk image is malformed` | 用 `PRAGMA integrity_check` 确认是否真损坏；若 ok，检查是否有人绕开 `db_uri()` 手写 `immutable=1` |
| 文档守卫红 | 文档数字变了：先改 `docs/资产盘点.md`，再改 `test_doc_claims.py` 的 REALITY |
| 数据缺口用例红 | 看 `docs/数据说明.md` 是否属付费边界；是则改为 skip 并写明理由 |
